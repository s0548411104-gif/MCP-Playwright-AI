# Weather MCP with Playwright - Israel Edition 🌤️

## מטרת הפרויקט
פרויקט זה מממש שרת MCP (Model Context Protocol) מותאם אישית המאפשר ל-AI Agents לברר את תחזית מזג האוויר בישראל. 
במקום להשתמש ב-API קונבנציונלי, ה-Agent משתמש בספריית **Playwright** כדי לפתוח דפדפן באופן אקטיבי, לנווט לאתר `weather2day.co.il`, לחפש את העיר המבוקשת, ולחלץ (RAG) את התחזית ישירות מתוך רכיבי ה-DOM בדף אל תוך הקונטקסט של השיחה.

## סטאק טכנולוגי
* **MCP SDK:** לחשיפת הכלים (Tools) למודל השפה.
* **Playwright:** לשליטה וניווט אוטומטי בדפדפן.
* **Gemini:** כמודל ה-LLM המפעיל (דרך Host ייעודי).

## איך להריץ את הפרויקט
1. התקנת התלויות וסנכרון סביבת העבודה (uv):
   ```bash
   uv sync

2. התקנת מנוע הדפדפן עבור Playwright:
     ```bash
    uv run playwright install chromium

3. הרצת הצ'אט (Host):
     ```bash    
     uv run host.py

## דוגמאות לשאלות שה-Agent יודע לענות
* "מה התחזית להיום ב[שם עיר]?"

* "האם צפוי לרדת גשם ב[אזור]?"

* "פתח את דפדפן מזג האוויר ובדוק מה הטמפרטורה ב[שם עיר]."
